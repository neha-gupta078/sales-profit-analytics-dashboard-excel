# sales-profit-analytics-dashboard-excel
Excel dashboard analyzing sales and profit by region, category and state



<img width="1635" height="786" alt="Sales_Profit_Dashboard" src="https://github.com/user-attachments/assets/e46b8a65-797d-4066-a03e-5d2aa768227b" />




## Objective
Find which regions, categories and states drive sales and profit.

## Tools
Advanced Excel, Pivot Tables, Slicers, Map Chart

## Dashboard Features
- KPI cards: Total Sales, Total Orders, Total Profit, Average Order Value
- Year and Quarter slicers
- Sales by region, category and state
- Average profit per order by region

## Key Insights
- North leads in sales with a 30% share
- Electronics is the top category
- East has the highest average profit per order
- Maharashtra is the top state
